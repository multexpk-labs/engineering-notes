# Production Change Checklist

Before changing a production system:

- Define the exact change.
- Confirm the affected service.
- Record the current configuration.
- Confirm a usable backup or rollback path.
- Check dependencies.
- Choose a maintenance window when appropriate.
- Apply the smallest safe change.
- Verify service health.
- Check logs and dependent services.
- Record the result.

For risky changes, use staged rollout or a test environment first.
