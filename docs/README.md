# Engineering Notes

This repository is the field notebook for MULTEXPK LABS: practical notes collected while building, operating, debugging, and researching software and infrastructure.

## Note categories

- Linux and VPS operations
- Networking, DNS, Cloudflare, TLS
- PHP and Laravel
- WHMCS and hosting platforms
- Databases and backend systems
- WordPress and WooCommerce
- WhatsApp and API automation
- AI, LLMs, Ollama, and coding agents
- Deployment and monitoring
- Debugging and incident analysis
- Architecture decisions and experiments

## Note format

Prefer concise, reproducible notes:

**Problem → Evidence → Diagnosis → Change → Verification → Lesson**

Include commands, expected output, environment assumptions, and rollback considerations when useful. Remove credentials, private infrastructure identifiers, customer information, and other sensitive data before publishing.
