# Incident Record Template

## Summary

One-paragraph description.

## Impact

Which service or capability was affected?

## Timeline

Record UTC timestamps for important events.

## Detection

How was the issue discovered?

## Evidence

Relevant logs, metrics, status checks, and configuration observations.

## Root Cause

Confirmed technical cause, with uncertainty clearly marked.

## Remediation

Immediate recovery actions.

## Preventive Actions

Monitoring, tests, automation, configuration, or documentation changes.

## Lessons Learned

What should change in future operations?
